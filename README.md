## Implementation brief

Build a future-facing, accessible, multilingual personal portfolio for **Jithin K**, positioned as a **Chief Innovation Officer (CIO)** specializing in AI innovation, intelligent automation, emerging technology and business transformation.

- **Technology:** Next.js App Router, React, TypeScript, Tailwind CSS, Lucide React, Motion for React (Framer Motion).
- **Languages:** English (`en`), Italian (`it`), Arabic (`ar`, RTL).
- **Design:** monochrome, editorial, minimal but futuristic, light by default with optional dark theme; two system typography roles.
- **Motion:** purposeful, performant, reduced-motion aware. Remotion only if a genuine pre-rendered video use case warrants it.
- **Content:** one typed source of truth and complete localized copy; placeholders clearly identified.
- **Quality:** accessible keyboard interactions, metadata, hreflang, sitemap, robots, Open Graph images, automated tests.
